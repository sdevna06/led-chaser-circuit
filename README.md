# LED Chaser Circuit

An LED Chaser project built using basic electronic components to create sequential LED blinking patterns.  
This project demonstrates simple timing and digital electronics concepts useful for beginners in embedded systems and hardware design.

---

## Features

- Sequential LED blinking effect
- Simple and beginner-friendly circuit
- Easy hardware setup
- Demonstrates timing and output sequencing
- Includes circuit diagram and demo files

---

## Components Used

- LEDs
- Resistors
- IC (555 Timer / CD4017 depending on your setup)
- Capacitors
- Breadboard / PCB
- Power Supply
- Connecting Wires
